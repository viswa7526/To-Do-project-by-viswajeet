# To-Do by Viswajeet

A clean, dark-themed to-do app sidebar built with HTML, CSS, and vanilla JavaScript.

## Features

- Sidebar navigation for Dashboard, My Tasks, Important, Completed, Categories, and Settings.
- Light/dark theme switch with the selected theme saved in the browser.
- Responsive quote card and a custom-styled navigation menu.
- Font Awesome icons.

## Run locally

1. Open this project folder in your code editor.
2. Start a local web server from the project folder (for example, with the VS Code Live Server extension).
3. Open `index.html` in the browser through the local server.

The quote image is loaded from `assests/quotes.png`, so keep the `assests` folder beside `index.html`. Font Awesome is loaded from a CDN and requires an internet connection.

## Project files

- `index.html` — sidebar markup.
- `style.css` — layout, colors, and theme styles.
- `script.js` — theme switch behavior and persistence.
